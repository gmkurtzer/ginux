# Gate 12 Reduced Evidence

- `topology-comparison.tsv`: final Linux and Ginux medians and the
  favorable-direction ratio for every fixed and scaled sysbench cell.
- `topology-scaling.tsv`: each system's median relative to its own one-vCPU
  result.
- `boot-topology-comparison.tsv`: observational three-sample boot
  distributions at one, two, and four vCPUs.
- `environment.tsv`: matched machine, memory, sample counts, and sysbench
  binary identity.

The raw logs and disposable disk overlays remain in
`build/benchmark/gate12-final/` and are intentionally excluded from Git. The
committed tables were generated by the topology summarizer, which rejects
incomplete cells and binary-identity mismatches.
