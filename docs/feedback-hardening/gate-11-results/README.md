# Gate 11 Reduced Evidence

- `topology-comparison.tsv`: Linux and Ginux medians and the favorable-direction
  Ginux/Linux ratio for every fixed and scaled sysbench cell.
- `topology-scaling.tsv`: each system's median relative to its own one-vCPU
  result.
- `boot-topology-comparison.tsv`: three-sample boot distributions at one, two,
  and four vCPUs.
- `environment.tsv`: matched machine, memory, sample counts, and sysbench binary
  identity.

The raw logs and disposable disk overlays remain in
`build/benchmark/rocky10-topology-matrix/` and are intentionally excluded from
Git. The committed tables are generated by `make benchmark-topology-compare`,
which rejects incomplete cells and binary-identity mismatches.
