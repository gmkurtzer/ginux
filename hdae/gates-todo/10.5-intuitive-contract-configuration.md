# Intuitive self-contained contract configuration and UX

## Source

Human review of Gate 10 found that profiles, templates, and low-level operation
identifiers provide a sound enforcement representation but are not an intuitive
primary configuration interface.

## Goal

Let a human describe an instance's complete userspace contract in the same
instance TOML using understandable access verbs, resource namespaces, and
bounded globs, then inspect and explain exactly how that recipe compiles into
the immutable Gate 10 operation table.

## Approved scope

- Add one self-contained `[userspace.contract]` configuration section with an
  explicit version, catalog version, and default decision.
- Add human-facing allow and deny groups for access verbs including read,
  write, execute, connect, listen, process authority, and system authority.
- Add documented canonical resource namespaces for filesystem paths, virtual
  `/proc` and `/sys`, devices, networking, processes, signals, time, identity,
  memory, and other Gate 10 catalog families.
- Support bounded `*` single-component and `**` recursive selectors expanded
  during validation, never matched dynamically at runtime.
- Make deny rules deterministically override grants and fail closed on invalid,
  ambiguous, or zero-match rules.
- Compile the human recipe into the explicit immutable Gate 10 operation table,
  provenance, and digest without weakening existing argument/resource checks.
- Keep the complete recipe in one instance file. Complete examples may be
  copied, but detached contract fragments and runtime preset dependencies are
  not operator-facing concepts.
- Provide `ginux instance` workflows to validate, inspect, explain, and diff
  complete instance recipes with actionable diagnostics.
- Preserve an explicitly marked advanced exact-operation escape hatch for
  expert troubleshooting and workloads not expressible through the primary
  vocabulary.

## Non-goals

- A graphical UI, browser service, remote policy service, or external policy
  database.
- Automatically granting observed behavior or silently weakening a recipe.
- Runtime policy mutation.
- Supporting legacy Gate 10 profile/template references as the primary saved
  recipe; migration behavior will be defined before implementation.

## Acceptance criteria

- One instance TOML completely describes the userspace contract without an
  external template, profile file, or policy database.
- Human rules compile reproducibly into the same explicit Gate 10 table and
  digest, with provenance connecting every operation to its source rule.
- `*` and `**` select only documented namespaces; malformed and zero-match
  selectors fail before instance launch.
- Deny precedence is deterministic and visible in check, show, explain, diff,
  and runtime audit output.
- Example instance recipes remain self-contained with no preset, profile file,
  policy database, or detached contract object.
- Advanced exact-operation rules cannot promote an unsupported operation or
  bypass managed argument/resource validation.
- Existing strict-denial and Rocky systemd behavior can be represented by
  self-contained recipes and retain their Gate 10 runtime evidence.
- `make demo-gate-10.5` validates, explains, compares, launches, and
  audits representative recipes without hidden dependencies.

## Decisions and limitations

- The human recipe is source of truth. The normalized operation table and
  digest are derived immutable evidence, not a second hand-edited policy.
- CLI configuration and explanation are the initial UI. A graphical UI is
  deferred unless separately approved.
- Access-verb groups classify catalog operations rather than weakening
  operation-specific argument and resource checks. Unsupported catalog
  authority cannot be promoted by either a glob or exact allow.
- The systemd preset intentionally grants every supported operation in each
  human access group and then denies raw packets and direct MMIO/DMA. This is
  authority-equivalent to the accepted Gate 10 systemd contract; it is a
  compatibility baseline, not a recommended least-authority recipe.
