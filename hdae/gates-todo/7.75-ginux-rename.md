# Ginux final project rename

## Source

Human direction on 2026-11-04 to rename Ginux-us to Ginux because the full
kernel project is pivoting to the userspace-kernel architecture.

## Goal

All active project and repository surfaces use Ginux as the product name while
the executable remains `ginux`, without changing behavior or moving the local
checkout directory.

## Approved scope

- Rename active product, architecture, build, source, configuration, fixture,
  output, cache, and documentation identifiers from Ginux-us to Ginux.
- Keep the executable and Rust package prefix as `ginux` and `ginux-*`.
- Rename the GitHub repository from `gmkurtzer/ginux-us` to
  `gmkurtzer/ginux` and update origin.
- Update deterministic stale-name verification and rerun the complete offline
  regression suite plus the Gate 7 demonstration.

## Non-goals

- Moving or renaming the local checkout directory; it remains
  `/Users/gmk/git/ginux-us` for later integration into the main Ginux project.
- Rewriting locked Gates 1-6, Git history, or historical pull-request content.
- Changing runtime architecture, security behavior, contracts, compatibility,
  or accepting Gate 7 automatically.

## Decisions and limitations

- The unchanged `ginux-us` directory name is an explicit human constraint and
  is not a product-name exception.
- Locked accepted gate records, Gate 7.5, and existing history retain former
  names as immutable lineage evidence.
- This is a behavior-preserving rename.
- The source product rename is complete, but repository delivery is partial.
  The existing non-empty `gmkurtzer/ginux` repository cannot be overwritten or
  repurposed without explicit integration direction.
